# Rastgele Varoluşsal Kriz Jeneratörü

## Giriş

Bu proje, insanlığın en temel ve en gereksiz ihtiyacı olan anlamsız düşünceleri otomatik olarak üretmek için tasarlanmıştır. Bilimsel araştırmalar (asla yapılmadı) göstermiştir ki, insanların %142'si günde en az 73 varoluşsal kriz yaşar. Bu yazılım, o krizleri sizin için üretir ki siz sadece oturup "neden" diye sorasınız.

## Kullanım

```bash
python kriz.py
```

Enter'a basın, kriz gelsin. Ctrl+C ile gerçek hayata dönün (veya dönmeyin).

## Özellikler

- Tamamen anlamsız
- Rastgele
- Sonsuz
- Türkçe
- Çalışıyor (gerçekten)
